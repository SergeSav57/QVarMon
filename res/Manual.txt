        Данную инструкцию можно сохранить в файл "QVarMon_Manual.pdf" в текущей
        директории, нажав кнопку "Сохранить в файл" внизу.
		
                Комплект приложений (VMS - Variable Monitoring Station)  предназначен для
        отладочных работ встроенных микроконтроллерных изделий и рассчитан на
        применение в составе прошивки микроконтроллеров (м/к типа STM32F40x и STM32F41x
        и их аналогов) файлов can.c и can.h, прилагаемых к поставке, и их соответвующей
        инициализации.
            Комплект состоит их следующих приложений:
            QVarMon   - основное приложение для мониторинга переменных, их выбора
                        из состава всех имеющихся в прошивке и запуска приложений,
                        входящих в состав VMS;
            QVarFile  - приложение для определения параметров(адрес, размер, тип)
                        глобальных переменных, массивов, структур в памяти м/к,
                        используя выходной файл компилятора gcc типа *.elf для
                        м/к типа STM32 и их аналогов;
            QVarChart - приложение для вывода в реальном времени графиков переменных;
            QVarArr   - приложение для мониторинга массивов переменных;

    1. Начало работы.
            При запуске приложения QVarMon производится поиск файлов в директории config, 
        содержащих описание конфигураций загрузок для различных устройств.
            Если файлы не найдены, последует информация о необходимости создать новый
        файл конфигурации загрузки. Иначе открывается окно "Конфигурации запуска". В окне
        дерева конфигураций необходимо выбрать способ загрузки файлов, соответствующих
        текущему устройству и нажать кнопку "Запуск" или произвести двойной щелчек мыши
        на данном пункте.
            Первый пункт в окне "Конфигурации" - "Создать файл параметров" : создание файла
        параметров из файла "*.elf", созданного компилятором GCC для исходных файлов
        программы для м/к со всеми ее глобальными переменными, включая структуры с
        единичным вложением и массивы.
            Далее следует дерево файлов конфигурации и действий, которое начинается с
        директории, содержащей файлы параметров. Директория должна располагаться в текущем
        каталоге и иметь имя "config".
            В каждой конфигурации есть следующие пункты и способы:
            -1. Имя файла "*.xml" конфигурации;
            -2. Имя конфигурации;
            -3. Загрузка из флеш-памяти;
                Предварительно файл параметров должен быть записан во флеш-память м/к.
                Запись осуществляется в окне "Редактор версии & Прошивка".
            -4. Загрузка из файла конфигурации;
                Файл параметров загружается из файла дискового пространства компьютера.
            -5. Редактор версии & Прошивка;
                - Изменение версии конфигурации загрузки.
                - Прошивка файла параметров во флеш-память м/к.
                  В данной версии приложения для м/к типа STM32F40x и STM32F41x
                  адрес записи файла параметров 0x080E0000.

        Для создания новой конфигурации, необходимо нажать кнопку "Создать".

        После выбора способа загрузки откроется окно "Выбор параметров для мониторинга".

    2. Окно "Выбор параметров для мониторинга".
            В окне имеются два поля: "Все параметры" и "Параметры для мониторинга". 
        В первом располагаются общее число параметров, загруженных в приложение.
        Во втором, параметры, которые необходимо проконтролировать.
        Выбранные параметры в дальнейшем, размещаются во вкладке наблюдаемых параметров
        главного окна приложения, указанной в раскрывающемся списке вкладок окна
        "Параметры для мониторинга".
            В раскрывающемся списке окнае "Все параметры" можнр выбрать какие параметры
        контролируются в режимах: простого мониторинга, выбор массивов, вывод на график,
        запись в файл в формате *.mon для дальнейшего просмотра в специальных программах
        типа "Gr". Так же файл можно загрузить в приложение "QVarChart.exe" в автономном
        режиме, входящего в состав данного приложения, для предварителього просмотра.
            Примечание: в режиме выбора параметров для графиков и записи в файл, доступны
                        только параметры, выбранные для режима простого мониторинга.
            Кнопки со стрелками ">>, <<, >, <" предназначены для пересылки выбранных строк
        параметров (двойные для всех параметров, одинарные для выбранных). Выбор
        параметров производится мышью и клавиатурой стандатными способами.
            Кнопки со стрелками "вверх, вниз" служат для перемещения выбранных параметров
        соответственно вверх или вниз относительно их места в списке.
            Нажатие на заголовки колонок "Имя" и "Узел" окна "Все параметры" производит
        сортировку соответственно имен параметров и имен узлов (каналов) по алфавиту
        (убывающему, возрастающему).
            Внизу окна, расположено поле "Фильтр", позволяющее найти интересующие имена
        параметров при вводе символов в поле по совпадению введенных символов и символов
        имен параметров.
            Кнопка "Зеленая галка" закрывает окно выбора, открывает основное окно приложения
        и заполняет вкладки мониторинга параметров.

    3. Основное окно приложения имеет следующие пункты и подпункты меню:
        - Файл;
            > Открыть вкладку - открывает файл с сохраненной вкладкой параметров;
            > Создать новую вкладку - добавляет новую вкладку к уже открытым;
            > Сохранить вкладку - сохраняет вкладку с именем ярлыка заголовка вкладки;
              Имя ярлыка заголовка по умолчанию "Вкладка Х", где Х текущий номер вкладки
              по порядку, которое можно изменить двойным щелчком мыши по имени, ввода
              нового и последующем нажатии клавиши "Ввод".
            > Выход - выход из приложения;
        - Параметры;
            > Выбрать параметры - открывает окно "Выбор параметров для мониторинга"(п.2);
            > Выбор конфигурации загрузки - открывает окно "Конфигурации запуска";
            > Вывод на график - описание ниже;
        - О программе;
            > О программе - версия приложения, кратко о его назначении.
            > Справка - вывод этого текста;

        Все подпункты меню продублированы кнопками на панели инструментов.

        Левое окно содержит вкладки выбранных параметров для мониторинга.
        Каждая вкладка содержит:
            - "N" -номер по порядку;
            - "Узел" -имя узла(канала);
            - "Имя" -имя переменной;
                Клик мыши по имени переменной открывает окно с ее адресом в памяти м/к.
            - "S" -переключатель системы счисления (DEC/HEX);
                Колонка "S" отображает текущую систему счисления отображаемого значения
                переменной: "D" - десятичное (DEC), "H" - шестнадцатиричное (HEX).
                Клик по полю "S" в стоке переменной покажет всплывющее меню для выбора
                системы счисления, а так же символ "B" для показа окна, отображающего
                значение переменной в бинарном коде.
                Клик по заголовку "S" переключает систему счисления сразу всех параметров
                во всех вкладках.
            - "Тип" -тип переменной.

        Правое верхнее окно содержит выбранные массивы для мониторинга.
        Клик по имени массива открывает окно для отображения данных массива.

        Нижнее правое окно содержит:
            - окно интерфейса CAN;
                Отображение имени устройства преобразователя USB-CAN, его серийного
                номера и выбора скорости (бод). Скорость должна быть равной скорости,
                установленной в м/к. Зеленый светодиод - соединение установлено,
                серый - не установлено.
            - окно активных каналов;
                Каждый светодиод содержит имя узла(канала), заданного в файле конфигурации
                загрузки и номер канала. Зеленый цвет - соединение установлено и файл
                параметров загружен, желтый цвет - соединение установлено, но файл
                параметров не загружен, серый цвет - соединение не установлено.
            - окно записи параметров в файл "*.mon";
                Кнопка "Выбор параметров для записи" открывает окно "Выбор параметров для
                мониторинга", где можно выбрать параметры для записи.
                Кнопка "Начать/Закончить запись" - начинает запись выбранных переменных и
                заканчиват. Во время записи кнопка мигает красным цветом.
                Индикатор времени записи - отображает время записи в файл с точностью
                1 сек.
